Part 1 — Polynomial Basis Functions

The Boston Housing data are split in their supplied order: the first 100 observations train each model and the remaining 406 observations test it. Predictor normalization uses statistics calculated from training data only.

1(a) Polynomial Degree

I fitted polynomial basis regressions of degrees 1 through 7 using all 13 features, without cross-terms or regularization. Training error falls steadily as the degree rises, while test error grows extremely quickly. This is strong overfitting: the higher-degree terms fit the small training set but generalize very poorly to the later observations.

1(b) Degree-One Weights

These are weights for standardized input variables, with the intercept listed first. The housing.names file labels average rooms as RM and distance to employment centres as DIS. RM has a substantial positive coefficient (4.195634), which is reasonable: more rooms tends to correspond to higher house value. DIS has a near-zero positive coefficient (0.010715) after the other features are included, so it contributes little in this fitted training sample; its direction is not especially intuitive on its own.

1(c) One-Dimensional Polynomial Fits

To visualize regression, I used the second data feature (ZN), as specified. The degree-one and degree-three curves are similar and only capture a weak overall relationship. The degree-eight curve bends substantially at the edge of the observed values and has worse test error, illustrating the instability of a high-order polynomial.

1(d) Regularized Degree-Eight Regression

Using only ZN and the first 100 observations, I evaluated each requested regularization constant with 10-fold cross-validation. The best average validation RMS error occurs at λ = 10. Regularization greatly improves on the unregularized degree-eight model.
